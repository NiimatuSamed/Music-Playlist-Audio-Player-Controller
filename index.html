enqueue(track)

Adds a new element to the REAR (end) of the queue. In JavaScript, this operates via Array.prototype.push(). 

enqueue(track) {
  this.items.push(track);
}
dequeue()

Removes and returns the element at the FRONT (index 0). In JavaScript, this operates via Array.prototype.shift(). 

dequeue() {
  if(this.isEmpty()) return null;
  return this.items.shift();
}

Why are Queues essential for audio streaming?

In digital media streaming, users expect seamlessly ordered playback. The queue structure ensures strict Fairness and Order Preservation: the song requested earliest is always played next. It acts as an asynchronous buffer between user interactions and audio thread execution.
